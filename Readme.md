🌿 FocusFlow – Productivity Management App

A modern and responsive productivity management web application developed using React.js. FocusFlow helps users organize daily tasks, manage personal notes, and improve productivity through a simple and attractive interface.

📌 Project Overview

FocusFlow is a Minor Project (Project 04) designed to make daily task management and note organization easier.

The application provides two main modules:

- To-Do App: Manage daily tasks efficiently.
- Notes App: Create and organize important notes.

The application uses browser Local Storage to save user data, so tasks and notes remain available after refreshing the page.

✨ Features

1. To-Do Management

- Add new tasks.
- Edit existing tasks.
- Delete tasks.
- Mark tasks as completed or pending.
- Filter tasks by status.
- View task statistics.

2. Notes Management

- Create new notes.
- Edit and update notes.
- Delete notes.
- Search notes by title or content.
- Filter notes by category.
- Organize notes into Personal, Work, and Study categories.
- Display the last updated date.

3. User Interface

- Modern green-themed dashboard.
- Sidebar navigation.
- Responsive layout for mobile and desktop.
- Attractive cards and buttons.
- Smooth hover effects.

4. Data Storage

- Uses browser Local Storage.
- Automatically saves tasks and notes.
- Retains data after page refresh.

⚙️ Installation and Setup

Follow these steps to run the project locally.

Step 1: Clone the Repository

git clone https://github.com/your-username/Minor-Project-04-FocusFlow.git

Step 2: Open the Project Folder

cd Minor-Project-04-FocusFlow

Step 3: Install Dependencies

npm install

Step 4: Start the Development Server

npm run dev

Step 5: Open in Browser

Open the local URL displayed in the terminal, usually:

http://localhost:5173/

🏗️ Production Build

To create a production build, run:

npm run build
